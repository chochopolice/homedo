参加のしかた

  1. 参加する人が自分のスマホでアプリを開く
  2. 「招待コードで参加する」をタップ
  3. コード8桁と自分の名前・アイコンを入力
  4. 「参加する」で完了。すぐに同じ家事リストが表示されます
招待コードは知っている人なら誰でも参加できます。LINEなど直接のやりとりで伝え、SNSやブログには貼らないでください。
スマホを持っていないお子さんの場合は、招待コードではなく、管理・設定タブの「メンバー管理」から名前を追加してください。共有のタブレットや親のスマホから、操作メンバーを切り替えて使えます。

おねだりから受け取りまで

  1. お小遣いがほしい人が金額を選んで「おねだり申請」を押す
  2. その時点でクレジットが差し引かれ、申請リストに「支払い待ち」で並ぶ
  3. 支払い担当（世帯をつくった人）の家事ボードの一番上に支払いタスクが表示される
  4. 実際に現金を渡したら「払った！(完了)」を押す
  5. 申請が「✅ 支払済み」に変わって完了
気が変わったときは、申請した本人が「取り消す」を押せばクレジットは全額戻ります。支払い担当の側からは「却下」として同じ操作ができます。

管理・設定タブ

家事を追加する

名前・周期・クレジットの3つを決めるだけです。周期は「何時間おきに『要実施』に戻すか」、クレジットは「1回やったらいくら分か」です。

目安例
毎日やること皿洗い・風呂掃除 → 1日ごと / 100〜200Cr
数日に一度トイレ掃除・買い出し → 2〜3日ごと / 250〜300Cr
週に一度シーツ洗濯・段ボール出し → 1週間ごと / 150〜300Cr
手間のかかる家事ほどクレジットを高くすると、面倒な家事も進むようになります。金額は「編集」からいつでも調整できます。

メンバーを追加する

スマホを持たないお子さんなど、共有端末から操作する人を追加できます。自分のスマホを持っている人は、招待コードで参加してもらってください。

バックアップ

「コピー」または「ファイル保存」で、いまのデータをJSON形式で書き出せます。大きな設定変更をする前に取っておくと安心です。読み込みは「インポート」からできます。

7機種変更・引き継ぎ

最初にアプリを開いたときは「おためしログイン」の状態です。この状態でブラウザの履歴やサイトデータを消すと、世帯に戻れなくなります。使い始めたら早めにGoogleアカウントを連携してください。

Googleアカウントを連携する

  1. 管理・設定タブを開く
  2. 「アカウント」の「Googleアカウントを連携する」を押す
  3. いつも使っているGoogleアカウントを選ぶ
  4. 警告バナーが消え、「連携済み」と表示されれば完了

新しい端末に移すとき

連携が済んでいれば、新しい端末でアプリを開いて同じGoogleアカウントでログインするだけです。連携していない場合は、ご家族の誰かに招待コードを教えてもらい、参加し直してください。データは世帯に残っているので消えません。

「この端末を世帯から切り離す」を押しても、家事やクレジットのデータは消えません。招待コードでいつでも戻れます。

8よくある質問

完了ボタンが押せません
その家事がまだ「ピカピカ」（周期の途中）だと押せません。表示されている「あと○時間」が経つと押せるようになります。また、操作メンバーが選ばれていないときも押せません。
家族の操作がこちらの画面に反映されません
通信が切れている可能性があります。管理・設定タブの一番上の丸が緑なら接続中、灰色ならオフラインです。電波の良い場所で画面を開き直してください。オフライン中の操作は、接続が戻った時点でまとめて反映されます。
間違えて完了を押してしまいました
完了の取り消し機能はありません。管理・設定タブでその家事を「編集」して開き直すか、次の周期を待ってください。
「払った！」ボタンが出てきません
このボタンは世帯をつくった人（支払い担当）にだけ表示されます。ほかの人の画面には出ません。
クレジットの金額を1円以外にできますか
できます。ただし現在は画面から変更できないため、設定の変更が必要です。管理者にご相談ください。
招待コードを変更できますか
現在は変更できません。外部に漏れてしまった場合は、新しく世帯をつくり直し、バックアップ機能でデータを移してください。
メンバーを削除するとどうなりますか
その人の保有クレジットも一緒に消えます。がんばり履歴の記録は残ります。自分自身は削除できません。
